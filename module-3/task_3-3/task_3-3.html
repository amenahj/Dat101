1. What is the difference between invoking and creating a function?

      2. Å lage en funksjon betyr at vi skriver kode som bestemmer hva funksjonen skal gjøre. Å kalle en funksjon betyr at vi kjører koden i funksjonen.

    2. Explain the syntax regarding semicolons and code blocks.

      3. Semikolon (;) brukes for å avslutte en setning i JavaScript. Kodeblokker bruker krøllparenteser {} for å samle flere kodelinjer.

    3. What happens when we try to store values from a function when it doesn't return any?

      4. Hvis en funksjon ikke returnerer en verdi, får vi undefined når vi prøver å lagre resultatet.

    4. How do we separate parameters from each other when creating a function?

      5. Vi bruker komma (,) for å skille parameterne fra hverandre.

    5. Explain how parameter names are related during the invocation and creation of a function.

      6. Når vi lager en funksjon, gir vi parameterne navn. Når vi kaller funksjonen, sender vi inn verdier. Verdiene kobles til parameterne i samme rekkefølge.

    6. Explain why a parameter is undefined when a function call is missing a parameter.

      7. Hvis vi ikke sender inn en verdi til en parameter, blir verdien undefined fordi parameteren ikke har fått noen verdi.

    7. Explain what happens when we use recursive functions.

      8. En rekursiv funksjon er en funksjon som kaller seg selv. Den fortsetter til en bestemt betingelse er oppfylt.
