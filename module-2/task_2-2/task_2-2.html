1. Where should you use constants, and where should you use variables? Can they all be constants?

    2. Bruk const når verdien ikke skal endres. Bruk let når verdien kan endres senere. Ikke alle verdier kan være konstanter, fordi noen verdier må kunne oppdateres i programmet.

  2. How do parentheses affect the arithmetic outcome of an expression?

    3. arenteser endrer rekkefølgen på beregningen. JavaScript regner først ut det som står inni parentesene

  3. How do we limit floating-point numbers to a given number of decimals?

    4. Vi kan bruke .toFixed(). For eksempel vil number.toFixed(2) vise tallet med to desimaler

  4. How can we compare two floating-point values to see if they are equal (is 12.199999 the same as 12.2)?

    5. Desimaltall kan noen ganger ha små avrundingsforskjeller. Derfor kan vi sammenligne forskjellen mellom tallene og sjekke om den er veldig liten

  5. What do comparison operators return, and how can we check if they are FALSE or TRUE?

    6. Sammenligningsoperatorer returnerer en boolsk verdi, altså true eller false. Vi kan bruke operatorer som >, <, >=, === og !==.

  6. How does the Math.random() function work, and what can it be used for?

    7. Math.random() lager et tilfeldig desimaltall mellom 0 og 1. Den kan brukes til å lage tilfeldige tall, for eksempel i spill eller tilfeldige valg.

  7. What is modulus (%), and when do we need this operator in mathematical operations?

    8. Modulus % gir resten etter en divisjon. For eksempel gir 131 % 7 resultatet 5. Det er nyttig når vi vil finne ut hvor mye som er igjen etter en divisjon
